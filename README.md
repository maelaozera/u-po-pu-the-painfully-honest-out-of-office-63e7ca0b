# The Painfully Honest Out-of-Office

Entry for the make.fun bounty
`u-po-pu-the-painfully-honest-out-of-office-63e7ca0b`.

`main.ts` (Node 22) writes a single out-of-office auto-reply — one
sentence, at most 200 characters — to `/output/entry.txt`. The reply
admits, politely, that the sender's inbox grew faster than they could
answer it, and promises a proper reply on their return.

Run it with:

```sh
node main.ts
```

The output is deterministic: every run writes the same bytes.
